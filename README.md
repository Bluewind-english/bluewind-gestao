# BlueWind – Gestão de Produção

App de gestão de produção da Bluewind Technology com a assistente **Turbine AI**.

- Cronograma, produção, alertas, mensagens, painel do dia, histórico e equipe
- Turbine: assistente com Modo Voz (português e inglês)
- Visual futurista com fundo espacial, triângulo holográfico e esfera de energia
